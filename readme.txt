== Description ==

**Awesome Widgets for Elementor** is a fast, lightweight, and modular Elementor add-on suite engineered to help freelancers, agencies, and store owners build complete, high-converting WordPress websites without writing a single line of code.

From editorial hero headings, company story layouts, and interactive step flows to full WooCommerce product grids, category showcases, carousels, and site-wide Header & Footer templates, every widget in the suite follows a unified architectural design system that automatically adapts to your theme's light or dark surfaces.

=== Why Choose Awesome Widgets for Elementor? ===

* **Global Design Token Sync:** Every widget connects directly to your Elementor Kit's Global Colors (`Primary`, `Secondary`, `Text`, `Accent`) and Global Typography presets out of the box—no manual re-styling required when switching brand palettes.
* **Light & Dark Mode Ready:** Built with modern CSS `color-mix()` surface tinting and scoped custom properties so cards, borders, dividers, and badges adapt naturally to any section background.
* **Plain-English, Intuitive Controls:** Clean, consistent control labels and organized tabs across all 34 widgets make page building fast and frustration-free for both developers and clients.
* **Lightweight & Performance-First:** Modular asset loading ensures styles and scripts only load when needed, with zero render-blocking bloat and optimized WordPress/WooCommerce queries.
* **WooCommerce AJAX Storefront Ready:** Product grids, lists, and carousels support instant AJAX Add-to-Cart with automatic "View Cart" state switching, sale tags, star ratings, and category filtering.
* **SEO & Accessibility Built In:** Includes Google `FAQPage` JSON-LD schema on the Accordion widget, `BreadcrumbList` schema support, semantic HTML heading tag selectors (`H1`–`H6`, `div`, `span`, `p`), full keyboard navigation, and `prefers-reduced-motion` support.
* **RTL & Mobile Responsive:** Full Right-to-Left (RTL) layout and carousel support alongside granular desktop, tablet, and mobile controls.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/awesome-widgets-for-elementor` directory, or install the plugin directly through the WordPress **Plugins > Add New** screen.

2. Activate the plugin through the **Plugins** screen in WordPress.

3. Open any page or template with Elementor and look for the **Awesome Widgets** and **Awesome Woo** categories in the widget panel.

== Frequently Asked Questions ==

= Does this plugin work with Elementor Free, or do I need Elementor Pro? =

Awesome Widgets for Elementor works 100% with the free version of Elementor. You do not need Elementor Pro—including for building and assigning site-wide Header and Footer templates with our Header Footer Builder widget.

= Can I add multiple widgets on a single page? =

Yes. All 34 widgets use uniquely prefixed CSS classes and isolated JavaScript initializers so you can combine multiple grids, carousels, tabs, and accordions on the same page without style or script conflicts.

= Do the widgets adapt to my theme's Global Colors and Fonts? =

Yes. Every widget connects directly to Elementor's Global Colors and Global Typography tokens out of the box, while still letting you override individual colors, spacing, borders, shadows, and typography per widget or per repeater item.

= Do the WooCommerce widgets support AJAX Add to Cart? =

Yes. The Product Grid, Product List, and Product Carousel widgets support WooCommerce AJAX Add to Cart out of the box and automatically switch the button to a **View Cart** link once an item is added.

= Are the widgets SEO-friendly and accessible? =

Yes. Every widget lets you choose semantic HTML heading tags (`H1`–`H6`, `div`, `span`, `p`), includes ARIA labels and keyboard navigation support (such as arrow-key navigation in the Accordion and accessible mobile menu drawers), and offers built-in JSON-LD structured data for FAQs and Breadcrumbs.

= Does it support RTL (Right-to-Left) languages and dark backgrounds? =

Yes. All carousels, grids, badges, and directional layouts include native RTL support, and surface styles automatically adapt whether you place widgets on light or dark section backgrounds.

= Will this plugin slow down my website? =

No. Assets are cleanly structured and modular, images support WordPress responsive sizes and lazy loading, and database queries are optimized (`no_found_rows`) for fast page loads.
