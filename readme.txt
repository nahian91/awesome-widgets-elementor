Showcase useful elements with zero-shadow architectural card styles for Elementor Page Builder.

== Description ==

Awesome Widgets for Elementor is a powerful, high-performance, and lightweight Elementor add-on that lets you easily showcase Number Boxes, Service Boxes, Team Members, Testimonials, Header & Footer Builders, Dynamic Breadcrumbs, List Groups, WooCommerce Catalogs, WordPress Posts, and more — all with a modern, zero-shadow card-style design. 

With its clean structure and deep customizability, you can quickly add stunning, responsive widgets to your Elementor-powered website without writing a single line of code. Perfect for enhancing visual appeal, conversion rates, and user engagement.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/awesome-widgets-for-elementor` directory, or install the plugin directly through the WordPress plugins screen.

2. Activate the plugin through the 'Plugins' screen in WordPress.

3. Open any page with Elementor and look for the **Awesome Widgets** category.

== Frequently Asked Questions ==

= Can I add multiple widgets on a single page? =

Yes, you can. Awesome Widgets for Elementor allows you to use multiple widgets and custom card styles on the same page without script conflicts.

= Can I change colors or customize the card styles? =

Yes! Every widget comes with extensive styling controls in the backend to match your brand colors, border radius, padding, and typography.
